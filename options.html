Tab protection

Manual unloading and startup auto-unload use separate safety profiles. Changing one profile will not silently change the other.

Exact list review mode Advanced

Benefit: review the exact candidate list before it runs. Trade-off: if Opera changes which tabs are eligible before confirmation, the operation cancels instead of adapting. This is useful when the tab set is stable, but confusing during session restoration when loading tabs become eligible at different times.

Manual unloading profile Popup and individual unloads

These protections apply when you manually unload a single tab or start a bulk unload from the popup or keyboard shortcut.

Startup auto-unload profile Automatic only

These safeguards apply only to the automatic startup scan. You can, for example, allow loading-tab attempts during startup while keeping loading protection ON for manual unloading.

Startup and time limits

Both adaptive modes repeatedly refresh the tab list while their bounded scan window is active. The hard overall deadline always wins.

Validation checks both operation budgets: the startup monitoring window, optional loading grace, empty-scan interval, and one tab attempt must fit inside the overall deadline; the manual adaptive scan window plus one tab attempt must also fit. Impossible combinations are rejected instead of silently saved.

Interface and shortcuts

These options do not change the tab eligibility policy.

Keyboard shortcut {Suggested: Ctrl+Shift+U}

Opens the popup and starts the selected bulk mode. In adaptive mode, confirmation is optional according to the setting above; exact review mode uses a fixed candidate list and may cancel if the list changes.

Change the shortcut in opera://extensions/shortcuts. The browser can reserve shortcuts for its own commands.
